# RCA 리포트 마스킹 규칙

리포트(`docs/rca/<시나리오>.md`)를 저장하기 전에 본문 · 표 · 명령 · 명령 출력 전체에 적용한다. 원본 로그는 건드리지 않는다.

| 유형 | 규칙 | 예 |
|---|---|---|
| IP (구분 불필요) | 뒤 옥텟을 `x` 로 바꾼다. 대역이 의미 있으면 앞 옥텟은 남긴다 | `10.20.x.x`, `10.20.3.x`, `127.0.x.x` |
| IP (구분 필요) | 역할 별칭으로 바꾼다. 같은 IP 는 리포트 전체에서 같은 별칭을 쓴다 | upstream 서버 `API-1` · `API-2`, 교사 단말 `교사단말A` ~ `교사단말D` |
| 이메일 | `<이메일>` 로 바꾼다 | `<이메일>` |
| 학생 식별자 | `STU-<숫자>` 와 학생 이름은 `학생A` · `학생B` … 로 바꾼다 | `reason=학생A 결석으로 재배포` |
| 토큰 · 세션 ID · API 키 | `<토큰>` 으로 바꾼다. 앞 몇 글자도 남기지 않는다 | `Authorization: Bearer <토큰>` |
| 비밀번호 · 접속 문자열 | 비밀번호와 계정이 든 접속 문자열 값은 `<비밀번호>` 로 바꾼다 | `-p<비밀번호>` |

- 명령에 IP 가 들어가면 별칭을 꺾쇠로 감싼 자리표시자로 쓴다. 예: `grep -n '<API-2>' $L/nginx-error.log`
- 학생 식별자가 든 로그 줄은 근거로 꼭 필요할 때만 인용한다.
- 별칭 대응은 작업 중에만 기억하고 파일로 남기지 않는다.
- 리포트 마지막 줄에 유형별 건수를 적는다.
  `마스킹 적용: IP N건 · 이메일 N건 · 학생 식별자 N건 · 토큰 · 세션 ID · API 키 N건 · 비밀번호 · 접속 문자열 N건`
- 저장 직후 `grep -nE '([0-9]{1,3}\.){3}[0-9]{1,3}|STU-[0-9]+|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[a-z]{2,}' docs/rca/<시나리오>.md` 로 남은 값이 없는지 확인한다.
